How it works

Two minutes. Then they’re living on both desktops.

  1. Download & open Mochi — pick dog, bird, or octopus.
  2. Menu → Invite friend… (copies a code).
  3. They claim it → you’re bonded. Feed, pet, poke, nap.
  4. Drag them to a screen edge to tuck them in for a nap.

If Mac says the app is “damaged”, run FIX IF MAC SAYS DAMAGED.command inside the unzipped folder — Gatekeeper being dramatic, not a real break.
