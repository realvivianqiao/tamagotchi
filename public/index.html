How it works

Two minutes. Then they’re living on both desktops.

  1. Download & open CoPet — pick dog, bird, or octopus.
  2. Menu → Invite friend… (copies a code).
  3. They claim it → you’re bonded. Feed, pet, poke, nap.
  4. Drag them to a screen edge to tuck them in for a nap.
  5. After this install, Check for updates… (Sparkle) installs new builds — no reinstall.

First open: right‑click CoPet.app → Open. If it says Apple couldn’t verify CoPet, go to System Settings → Privacy & Security → Open Anyway. Still stuck? Run FIX IF MAC SAYS DAMAGED.command next to the app (ad‑hoc signed — fine for friends; wider release needs Apple Developer ID + notarization).
